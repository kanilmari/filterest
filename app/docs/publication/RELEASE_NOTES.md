# Filterest 9.6.15

Ordinary Docker installations can connect to the existing site assistant. The optional connection uses the site’s Unix socket with a dedicated permissions group and an upload folder.

On wide screens, the experimental frosted menu and filter panel show the view’s background picture beneath them when docked beside the content. A Home background video leaves the bars plain.

The database stays at 9.13.9. This release adds no database migrations.
