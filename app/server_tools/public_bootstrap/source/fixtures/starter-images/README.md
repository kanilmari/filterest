# Filterest starter-row images

These reviewed JPEG fixtures are the user-approved neutral placeholder images
for the single service, risk, and ticket starter rows. The reviewed PNG source
material is converted to real JPEG data, and each role includes the exact
runtime `original`, `300`, `1000`, and `2160` display variants produced with
Filterest's own image-resizing path. The public generator assigns deterministic
storage filenames and database metadata.
